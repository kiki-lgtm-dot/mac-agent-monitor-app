iPhone · iCloud 私有同步

默认关闭。开启后，精简快照会离开这台 Mac，写入你 Apple ID 的 CloudKit 私有数据库。

仅保留在本机Prompt、任务摘要、项目与文件路径、模型、API Key、备忘录、翻译正文。
发送到私有 iCloudAgent/工具类别、运行状态、时长和 Token。对话标题默认不发送。
首次开启会用不可逆 SHA-256 键绑定当前 iCloud 账户，不保存或展示原始账户记录 ID。切换 iCloud 账户前，请先在这里关闭同步并确认旧账户数据已删除。
开启私有同步只要你主动开启，刷新后才会节流上传。关闭时同时删除云端 latest 记录。
包含对话标题标题可能暴露工作内容；必须单独确认，默认关闭。
