# Security Policy

## Reporting a vulnerability

Please do not publish exploitable details, credentials, private logs, or user data in a public issue. Use GitHub's private vulnerability reporting feature when it is enabled for this repository. If private reporting is unavailable, open a minimal issue asking the maintainer for a private contact channel without including the vulnerability details.
