# Contributing to Aivulet

Thanks for helping improve Aivulet.

1. Open an issue for behavior changes or new data-source adapters before a large pull request.
2. Keep monitoring read-only and preserve the distinction between tool state, agent activity, and measurable token evidence.
3. Run `./scripts/test.sh` and `./ApplePlatforms/iOS/scripts/validate-project.sh` before submitting.
4. Add sanitized fixtures for parser changes. Never commit real conversations, project paths, account identifiers, credentials, signing files, or usage exports.
5. Keep public UI strings available in both Simplified Chinese and English.
