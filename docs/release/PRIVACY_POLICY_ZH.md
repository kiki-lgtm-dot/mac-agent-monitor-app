## 1. 适用范围

本政策适用于 MAC版灵动岛--Agent运行监测 的 macOS 应用，以及在提供时的 iPhone 伴侣应用（统称“本应用”）。Mac 应用用于在顶部面板中查看本机 AI Agent 的运行状态与 Token 用量，并提供网站快捷入口、备忘录和用户主动触发的翻译学习功能；iPhone 应用用于查看用户选择同步的精简 Agent 状态摘要。

Mac 端 CloudKit producer 和 iPhone 端 receiver 的代码链路已实现，producer 的本地 CLI/回归验证已通过。但在正式 Developer ID CloudKit entitlement/provisioning profile、Production Container/schema、同一 iCloud 账号的 Mac→iPhone 真机链路和可提交 Archive 全部验收前，不能宣称同步已具备上线条件。本政策发布前必须再次与最终签名构建和 App Privacy 回答核对。本政策不对用户选择的第三方 AI 服务、网站、浏览器或其他应用自身的数据处理行为负责；这些服务适用其各自的隐私政策。

## 2. 核心原则

- Agent 与工具发现、日志解析、Token 聚合和工作台存储默认都在用户的 Mac 上完成。
- iCloud 私有同步默认关闭；只有用户阅读离机字段说明并明确同意后才会上传精简快照。
- 本应用不会将 Agent prompt、回复正文、项目文件或工作区内容上传给开发者。
- 翻译功能只有在用户输入文本并明确点击“仅翻译”或“学习解析”后才会联网。
- 本应用不含广告、跨应用追踪、分析 SDK 或开发者自建遥测服务。

## 3. 在本机读取和处理的数据

### 3.1 Agent、IDE 与日志信息

为了提供监控功能，本应用会在本机只读检查：

- 常见 AI/IDE 应用是否安装、是否正在运行及其扩展清单；
- Codex 本地 SQLite/JSONL 日志、Claude Code 本地 JSONL 日志；
- 用户通过文件选择器、绝对路径或连接码主动添加的自定义 JSONL 数据源；
- 日志中可用的会话标题、Agent 名称、模型名、项目路径、状态、时间戳、工作时长、Token 统计及来源归因信息。

这些数据用于在本机生成实时状态、历史用量、工具和会话视图。应用不会根据运行时长估算不存在的 Token 数据，也不会把上述日志上传到开发者服务器。部分标题、路径或日志内容可能由其他应用生成，并可能包含用户认为敏感的信息；用户可使用本应用的隐私遮罩隐藏部分显示字段。

### 3.2 工作台内容

用户创建的网站快捷入口、备忘录和保存到学习本的翻译结果存放在：

`~/Library/Application Support/AgentIsland/workspace.json`

网站仅在用户点击“打开”后交给 macOS 默认浏览器。本应用不会在后台抓取这些网页的正文。

### 3.3 本地设置与凭据

- 界面语言、翻译服务地址、模型名、自定义数据源路径及翻译 Token 汇总等设置保存在本机偏好设置中。
- 翻译 API Key 保存到 macOS Keychain，并设置为仅本设备解锁后可访问。
- Web 界面只能得知是否已经配置密钥，不能读取密钥本身。
- API Key 不写入工作台文件、Web localStorage、诊断快照或应用日志。

### 3.4 iPhone 本地缓存

iPhone 会从当前登录用户的 CloudKit 私有数据库读取固定快照，经大小、schema、时间戳、文本和 Token 一致性校验后原子写入 iPhone 沙盒。缓存目录使用 CloudKit 用户记录标识符的不可逆 SHA-256 摘要区分账号。同一账号验证后如遇临时 CloudKit 错误，应用可显示该账号上次有效缓存并标记离线；退出或切换 iCloud 账号时，不会回退到其他账号的缓存。

### 3.5 内置离线 Agent 监测示例

Mac 应用提供需由用户主动开启、持续以紫色标记的内置离线示例。该模式只替代 Agent 监测看板中的 Agent、会话、时长与 Token 值；工作台中的备忘录、网站和学习条目仍是用户的普通本机内容，不会被表示为示例。虚构快照每次在内存中重建，本机只保存一个示例模式布尔开关。示例期间不读取 Agent 日志、主目录授权或自定义源路径，并阻止翻译/外链网络操作与 CloudKit 访问。用户退出并重置后，开关和虚构快照被清除，真实监测保持关闭，除非用户再次明确开启。

## 4. 翻译功能与网络传输

翻译功能是可选功能。用户主动提交后，本应用会将以下内容发送到界面中显示并由用户配置的 OpenAI-compatible API 端点：

- 用户当前提交的文本；
- 源语言、目标语言、翻译或学习模式；
- 用户选择的模型名；
- 要求服务返回结构化翻译、定义、拆解、关键词和例句的系统指令；
- 如已配置，用于该端点鉴权的 API Key。

当前开发版本的默认端点地址指向 DeepSeek API，但用户可以在设置中更换为其他受支持的 HTTPS 端点或本机 loopback 服务。开发者不接收翻译请求或结果。网络会话采用临时配置，不使用 Cookie 或 URL 缓存，只允许同源重定向，并对响应大小设置上限。

如正式版保留该默认值，用户应注意：DeepSeek 当前公布的[隐私政策](https://cdn.deepseek.com/policies/zh-CN/deepseek-privacy-policy.html)称，其所覆盖的境内运营中收集和产生的个人信息存储于中华人民共和国境内，输入和对应输出可能在其所述条件下用于模型训练和服务优化。但该政策同时明确，终端用户访问开发者基于开放平台开发的下游应用时，其具体个人信息处理规则不在该政策的说明范围内；[DeepSeek 开放平台服务协议](https://cdn.deepseek.com/policies/zh-CN/deepseek-open-platform-terms-of-service.html)要求下游应用运营者告知处理规则并取得合法性基础。截至 2026-09-02，上述公开材料没有为本下游应用的 API 请求公布固定保留期，也没有提供 API 专用的“不用于训练”承诺，因此本应用不作出这两项承诺。

第三方端点可能接收网络连接所必需的 IP 地址、请求元数据和用户提交的文本，并可能依据其自身条款保存或处理这些信息。用户在使用前应查看所选服务的隐私政策和数据保留规则，不应提交无权披露的机密、个人或受监管信息。

翻译结果默认只保留在当前应用内存中；只有用户点击“存入学习本”时，原文和结果才写入本机工作台文件。服务返回的 Token 用量会以本机汇总计数形式保存。

## 5. CloudKit 同步、开发者收集、共享和追踪

可选 iCloud 私有同步默认关闭。用户首次开启时，应用会明确说明数据将离开 Mac；用户确认后，Mac 才向其 Apple ID 对应的 CloudKit 私有数据库写入一条固定 `latest` 记录。精简快照包含 Agent/工具类别与安全显示名、状态、工作时长、Token 统计、时间戳、计数和临时序号标识。它不包含 prompt、任务摘要、回复正文、项目/文件路径、模型名、API Key、备忘录或翻译内容。

完整对话标题默认不发送。只有用户通过单独的敏感字段确认后，明确标记为标题的来源值才可经过长度、路径和密钥样式过滤后写入快照。iPhone 每次启动仍默认隐藏这些标题，Live Activity 永不包含标题。

Widget Extension 不连接 CloudKit，也没有 iCloud entitlement；iPhone 主 App 只把不含标题的数量、状态、时长、Token 和更新时间交给 ActivityKit。Live Activity 仅在主 App 启动、回到前台或用户手动刷新时获得新状态，不使用 APNs 后台远程更新。两分钟无主 App 更新后，系统界面会标记状态过期；App 重启时可从 ActivityKit 恢复已存在活动的控制状态。

CloudKit 由 Apple 提供，记录位于用户的私有数据库，不经过开发者运营的同步服务器。该同步数据在 App Privacy/Privacy Manifest 中按“Other Usage Data”、“与用户关联”、“App Functionality”和“不用于追踪”披露。由于当前发布候选版保留可选标题同步，macOS 与 iOS App 的隐私清单也已经声明“Other User Content”、与用户关联、用于 App Functionality 且不用于追踪；提交前必须在 App Store Connect 使用相同口径。Apple 对 iCloud/CloudKit 的处理另受其条款和隐私政策约束。

除上述用户选择的 CloudKit 路径及第 4 节的主动翻译请求外，当前版本：

- 不向开发者运营的服务器发送数据；
- 不出售用户数据；
- 不将数据用于广告、广告衡量或跨应用/网站追踪；
- 不集成第三方分析、广告或崩溃报告 SDK；
- 不创建用户画像或进行自动化身份识别。

如果未来增加其他远程同步、账号、分析、崩溃报告、APNs 远程 Live Activity 更新或开发者托管的翻译服务，开发者将在功能上线前更新本政策、应用内说明和 App Store 隐私标签，并在需要时取得用户同意。

## 6. 数据保留与删除

本机数据会保留到用户删除相应内容或本地文件为止：

- 网站、备忘录和学习条目可在应用内逐项删除；
- 自定义数据源可在“数据源”界面移除；移除连接不会删除原始 JSONL 文件；
- 翻译 API Key 可在翻译器设置中清除；
- Codex、Claude Code 和其他工具的原始日志由对应工具管理，本应用不会删除或修改；
- 用户在 Mac 上关闭私有同步时，应用会立即停止上传并请求删除 CloudKit 私有数据库中的 `latest` 记录；删除需要 iCloud/网络可用，用户应根据应用状态确认或重试。iPhone 下次刷新发现记录不存在时，会只清除当前 iCloud 账号的本地缓存；
- 完整移除本应用时，macOS 可能仍保留 Application Support、偏好设置和 Keychain 项目，用户可按[支持页面](https://kiki-lgtm-dot.github.io/mac-agent-monitor-app/support/)提供的卸载说明清理，或联系[支持邮箱]。

开发者不提供独立应用账号或开发者运营的数据服务器，因此通常无法查看、导出或代用户删除本机或 CloudKit 私有数据库中的数据；用户应使用上述应用内删除和同步关闭控件。

## 7. 安全措施

本应用以只读方式处理受支持的外部日志，限制自定义数据源的文件类型、数量和大小；工作台文件使用原子写入并设置本机文件权限；API Key 存储于 macOS Keychain；翻译请求限制为 HTTPS 或本机 loopback HTTP，并限制重定向和响应大小。任何软件都无法保证绝对安全，用户仍应保护 Mac 登录账户、磁盘和 API 凭据。
