Agent 没有被检测到

  1. 在“设置 → 本机数据访问”确认监测已开启。
  2. Mac App Store 版需要用系统选择器授权当前用户的主目录。若更换了用户、迁移了数据或授权失效，请点击“重新授权”。
  3. 打开对应工具并让 Agent 产生一次新的结构化本地记录，然后点击“立即刷新”。只打开 VS Code 不等于 Agent 正在工作。
  4. 不在默认位置的 JSONL 可在“高级 · 自定义数据源”中通过文件选择器连接；Mac App Store 版仅支持已授权主目录内的自定义来源。

为什么 Token 显示为不可用

工具“已安装”、宿主应用“正在运行”与“存在可归因的 Agent Token 数据”是三件不同的事。本应用只显示来源实际报告的计数，不用运行时长估算。某些 IDE 扩展只提供进程或安装证据，因此可以显示运行中，但 Token 仍为“—”。

灵动岛悬浮与收起

鼠标进入屏幕顶部紧凑胶囊后会展开面板，移出后稍作延迟自动收起。也可单击展开，在面板外单击或按 Esc 收起。如位置不对，使用菜单栏图标中的“移到鼠标所在屏幕”。

无日志时体验离线示例

在“设置 → 离线示例模式”点击“查看内置示例”，或使用状态栏菜单的同名开关。紫色标记下的 Agent、会话、时长和 Token 都是虚构数据。此时不读本机 Agent 日志或自定义源，不访问网络或 iCloud；备忘录、网站和学习条目仍是你的本机内容。从设置中点击“退出并重置示例”后，如需真实数据，还需再手动开启监测。

iPhone 看不到 Mac 状态

确认 Mac 和 iPhone 登录同一 Apple ID、iCloud Drive 可用，且 Mac 上已主动开启“iPhone · iCloud 私有同步”。同步默认关闭，并可能因网络或 CloudKit 暂时错误而延迟。Live Activity 不使用后台推送，它会在 iPhone 主应用启动、回到前台或手动刷新时获取新状态。

翻译返回 401 或其他错误

401 通常表示 API Key 缺失、无效或不属于当前 Base URL。在“设置 → 翻译与释义服务”检查 Base URL、模型名和密钥，并确认账户余额、模型权限和网络状态。应用只允许 HTTPS 或本机 loopback HTTP 端点。

卸载与删除本机数据

先在设置中关闭 iCloud 私有同步并等待删除成功，然后清除翻译 API Key、撤销主目录授权并退出应用。将应用移到废纸篓后，macOS 仍可能保留 Application Support、偏好设置和 Keychain 项。这些位置可能随正式 Bundle ID 变化，因此删除前请在支持工单中提供应用版本和“关于”页显示的 Bundle ID，维护者会给出与该版本对应的精确、可验证清理步骤。

提交有效问题报告

请提供 macOS/iOS 版本、应用版本、Mac 型号与屏幕数量、问题复现步骤、期望/实际结果，以及不含私密内容的界面截图。若不能安全脱敏，请不要附加截图或日志。

Support

Need help from the maintainer? Open a GitHub Issue. Never attach Agent logs, prompt/response bodies, API keys, Apple signing material, real project paths, or conversation titles.

An Agent is not detected

  1. Confirm monitoring is enabled under Settings → Local Data Access.
  2. The Mac App Store build requires Home-folder authorization through the system picker. Reauthorize after a user change, migration, or expired permission.
  3. Let the Agent create a new structured local record, then select Refresh now. Opening VS Code alone does not mean an Agent is working.
  4. Connect non-default JSONL data under Advanced · Custom sources using the file picker. Mac App Store custom sources must be inside the authorized Home folder.

Why token usage is unavailable

Installed, host app running, and attributable Agent token telemetry are different facts. The App displays only source-reported counts and never estimates them from elapsed time. Some IDE extensions expose only process or installation evidence, so they can appear as running while token usage remains “—”.

Hover and collapse behavior

Move the pointer into the compact top-of-screen pill to expand it; moving out collapses it after a short delay. You can also click to expand and click outside or press Escape to collapse. If placement is wrong, choose Move to Display Under Pointer from the menu bar item.

Explore the offline example without logs

Choose Explore built-in example under Settings → Offline example mode, or use the matching menu-bar item. Agent, conversation, duration, and token values under the purple label are fictional. The mode does not read local Agent logs or custom sources and does not access the network or iCloud; notes, websites, and study entries remain your ordinary on-device content. After Exit & reset example, enable monitoring explicitly if you want to return to real data.

The iPhone cannot see Mac state

Verify both devices use the same Apple ID, iCloud Drive is available, and Private iCloud sync was explicitly enabled on the Mac. Sync is off by default and can be delayed by network or CloudKit errors. Live Activities have no background push path and refresh when the iPhone host app launches, returns to foreground, or is manually refreshed.

Translation returns 401 or another error

HTTP 401 normally means the API key is missing, invalid, or does not belong to the current Base URL. Check Base URL, model, and key under Settings → Translation and explanation service, plus provider balance, model access, and network availability. Only HTTPS or local loopback HTTP endpoints are accepted.

Uninstall and remove local data

First turn off private iCloud sync and wait for confirmed deletion, clear the translation API key, revoke Home-folder access, and quit. After moving the App to Trash, macOS may retain Application Support, preference, and Keychain items. Exact locations can change with the final Bundle ID; open a support issue with the App version and Bundle ID shown in About to receive precise, verifiable cleanup steps for that version.

Submit an effective report

Include macOS/iOS and App versions, Mac model and display count, reproducible steps, expected and actual results, and a UI screenshot only if it contains no private content. Do not attach a screenshot or log if it cannot be safely redacted.
