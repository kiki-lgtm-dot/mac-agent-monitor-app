# MAC版灵动岛--Agent运行监测 App Icon

`AgentIsland-AppIcon.svg` is the deterministic source artwork for the macOS and iOS icon. It uses only original geometric shapes and the product's existing dark, mint, cyan, and blue palette. It contains no text, Apple artwork, third-party logo, transparency, or reference-project asset.

Run `scripts/render-app-icons.sh` to generate the macOS `.icns` file and the iOS App Icon asset catalog from this source.
